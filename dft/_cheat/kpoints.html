The short version

  1. Use a Γ-centred mesh unless you have a reason not to. It is required for fcc and rhombohedral cells and for the tetrahedron method (ISMEAR = -5); hexagonal cells take a Γ-centred mesh or one shifted by 1/3 in the plane.
  2. Make the subdivisions proportional to the reciprocal-lattice lengths: a long real-space axis gets few k-points, a short one many. KSPACING does this for you.
  3. Converge the mesh for the quantity you report. Compare meshes by the number of irreducible k-points VASP finds, not by N.
  4. Metals need about ten times more k-points than insulators.
  5. With no KPOINTS file, VASP uses KSPACING = 0.5, which is coarse for metals.
  6. Band structures: a path in line mode, read with ICHARG = 11 for LDA/GGA, or a KPOINTS_OPT file (VASP 6.3.0 and later). Hybrids never use ICHARG = 11.

k-mesh from your POSCAR

Paste a POSCAR and choose a spacing. The calculator applies the same rule as KSPACING, guesses the lattice type from the cell shape, and writes the KPOINTS file. It runs in your browser.

The ways to write KPOINTS

Line 1 is a comment. Line 2 is 0 for an automatic mesh, or the number of k-points (or points per segment). Only the first character of line 3 matters: G Γ-centred, M Monkhorst–Pack, L line mode, A fully automatic; for lists and generating vectors, C or K means Cartesian and anything else fractional (reciprocal).

VASP writes the irreducible points of every automatic mesh to IBZKPT, in the explicit-list format; edit a copy of it rather than typing a list by hand. Generating vectors (line 3 Reciprocal or Cartesian with three vectors and a shift) give generalized meshes, such as a conventional-cell mesh on a primitive cell.

The tetrahedron method (ISMEAR = -5) needs a Γ-centred mesh with at least 4 k-points, whatever the lattice. When a mesh does not fit the lattice symmetry, VASP reports it in a message from its routine IBZKPT about the “generating k-lattice”; change the mesh rather than ignoring it.

How dense

For a spacing Δk = KSPACING in Å⁻¹ (2π included), VASP takes Ni = max(1, ⌈|bi| · 2π / Δk⌉), where bi are the reciprocal vectors without the 2π (bi · aj = δij). For an orthogonal cell, |bi| = 1/ai: silicon's 5.43 Å cubic cell at Δk = 0.25 Å⁻¹ gets ⌈1.157 / 0.25⌉ = 5 subdivisions per axis.

Rules of thumb for the full Brillouin zone

  • Insulators: about 100 k-points per atom bring the energy error below 10 meV.
  • Metals: about 1000 per atom for the same accuracy.
  • Transition metals with a steep DOS at the Fermi level: up to 5000 per atom for about 1 meV per atom.
  • Even meshes (8 × 8 × 8) are efficient up to N = 8; beyond that, odd meshes (11 × 11 × 11).
  • Compare an energy difference between cells only with consistent meshes: for commensurate supercells, use the same k-point set.

Count “k-points per atom” as N1 × N2 × N3 × (atoms in the cell).

The k-point tags

Check the mesh VASP used

grep "irreducible k-points" OUTCAR   # how many points the mesh reduced to by symmetry
grep NKPTS OUTCAR                    # the same number, with the number of bands
head -3 IBZKPT                       # line 2: number of irreducible k-points
vasp_std --dry-run                   # VASP 6.4 and later: writes IBZKPT and stops

The irreducible count sets the cost and suggests KPAR: choose a divisor of the number of MPI ranks that is at most this count.

Common mistakes

  • Monkhorst–Pack with even N for fcc or hexagonal cells: lower symmetry, slower convergence, or an IBZKPT error.
  • No KPOINTS file, so VASP silently uses KSPACING = 0.5 Å⁻¹; or a forgotten KPOINTS file that silently overrides KSPACING.
  • Mixing conventions: a VASPKIT 0.04 is a KSPACING of 0.25; pymatgen's reciprocal_density is a density, not a spacing.
  • Judging convergence by N when comparing even and odd meshes: compare irreducible counts instead.
  • A line-mode KPOINTS in a self-consistent run.
  • A path from one tool used on a differently oriented or non-standard cell.
  • The tetrahedron method with fewer than 4 k-points, a shifted mesh, or for forces in metals.
  • A KPOINTS_OPT file left in the folder: VASP reads it automatically.
  • With spin–orbit coupling, a k-point set that depends on the spin direction: test ISYM = -1.
