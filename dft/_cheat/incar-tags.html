The short version

  1. Set ENCUT yourself, the same in every run you compare, and at least 1.3 × the largest ENMAX of your POTCAR when the cell relaxes.
  2. Choose the smearing: ISMEAR = 0 ; SIGMA = 0.05 for insulators, ISMEAR = 1 ; SIGMA = 0.2 to relax metals, ISMEAR = -5 for final energies and DOS. Not sure? ISMEAR = 0 ; SIGMA = 0.1.
  3. Tighten EDIFF to 1E-6.
  4. Whenever NSW > 0, set IBRION (2 to relax) and a negative EDIFFG, such as -0.02 eV/Å.
  5. Switch on LASPH for d and f elements, meta-GGA and hybrids, and set LMAXMIX to 4 (d) or 6 (f).
  6. Read back what VASP understood: OUTCAR lists every value it used (commands below).

Build or check an INCAR

Choose the task and describe the system, and the builder writes a commented INCAR from the rules on this sheet. Paste an INCAR you already have into the checker to catch the common traps. Both run in your browser; nothing is uploaded.

How VASP reads the INCAR

  • Each statement is TAG = value. Put several on one line with ; between them.
  • # or ! starts a comment.
  • A \ at the end of a line continues the statement on the next line. Leave no space after it.
  • N*value repeats a value in array tags such as MAGMOM: 4*5.0 is four atoms at 5 μB.
  • Logical values are .TRUE. and .FALSE.
  • Avoid tabs: lines with tabs have broken the parsing with some compilers.
  • VASP acts only on the tags it knows. Check that every tag you set appears in OUTCAR with the value you meant (how), or run vasp_std --dry-run first (VASP 6.4 and later): it parses the input and stops before computing anything.
SYSTEM = bcc Fe, two-atom cubic cell   # comments start with # or !
ISPIN  = 2
MAGMOM = 1*3.0 \
         1*3.0                         ! one value per atom, continued with a backslash
ISMEAR = 1 ; SIGMA = 0.2               ! two statements on one line

Defaults that bite

VASP runs without most tags, using its defaults. These are the defaults that most often give a wrong or wasteful result.

NSW > 0 with no IBRION

IBRION then defaults to 0, molecular dynamics, which has no default time step: VASP stops at once.

Set IBRION = 2 to relax.

ISMEAR = 1 on an insulator

Methfessel–Paxton smearing (the default) can give unphysical occupancies in a gap; phonon frequencies can be off by more than 20%.

ISMEAR = 0, or -5 for static runs.

No ENCUT

The cutoff becomes the largest ENMAX of the POTCAR, so it changes with the elements: energies of different compounds are not comparable, and it is too low for cell relaxations.

Set it in every INCAR.

EDIFFG left at its default

The default is 10 × EDIFF, positive, so the relaxation stops on a small energy change while forces can still be large.

EDIFFG = -0.02 (a force criterion).

EDIFF = 1E-4

Loose for forces, stress and anything you report.

EDIFF = 1E-6; 1E-7 or tighter for phonons.

LASPH = .FALSE.

Stays off even when you set METAGGA, though meta-GGA, hybrids, DFT+U and 3d or f elements need the non-spherical terms.

LASPH = .TRUE.

LMAXMIX = 2

A DOS or band run that reads CHGCAR (ICHARG = 11) of a d or f system can then differ from the self-consistent run.

4 for d, 6 for f elements, in both runs.

No MAGMOM

Every atom starts at 1 μB, all parallel: an antiferromagnetic or high-moment state may never be found.

Set one value per atom, in POSCAR order.

LWAVE = .TRUE.

WAVECAR is written at the end of every run, often gigabytes.

LWAVE = .FALSE. unless a later run reads it.

No KPOINTS file

VASP falls back on KSPACING = 0.5 Å⁻¹, coarse for metals; and a stray KPOINTS file silently overrides KSPACING.

Write a KPOINTS file, or set KSPACING yourself.

NPAR from an old template

If NPAR and NCORE are both set, NPAR wins.

Delete NPAR; keep NCORE.

Symmetry kept by default

A relaxation keeps the symmetry of the starting structure, so a lower-symmetry minimum is out of reach.

Displace atoms slightly in POSCAR to break it.

Choosing ISMEAR and SIGMA

Smearing decides how electrons occupy states near the Fermi level. It is the setting most often left at a bad default.

Recipes by task

Each block is a complete starting INCAR. Replace the ENCUT of 520 eV with your converged value, and keep it the same across a workflow. The usual chain is: relax the cell → relax again from CONTCAR until the volume stops changing → static run → DOS and band structure from its CHGCAR.

ENCUT  = 520          ! at least 1.3 x the largest ENMAX: the cell changes (Pulay stress)
PREC   = Accurate
EDIFF  = 1E-6
ISMEAR = 0 ; SIGMA = 0.05   ! insulator; for a metal use ISMEAR = 1 ; SIGMA = 0.2
IBRION = 2            ! conjugate gradient; 1 (RMM-DIIS) once close to the minimum
ISIF   = 3            ! atoms, cell shape and volume
NSW    = 100
EDIFFG = -0.02        ! stop when every force is below 0.02 eV/A
NELMIN = 4            ! at least 4 SCF steps per ionic step
LCHARG = .FALSE. ; LWAVE = .FALSE.

Then: cp CONTCAR POSCAR and run again until the volume stops changing (the basis was set up for the starting cell). Finish with a static run.

ENCUT  = 520
PREC   = Accurate
EDIFF  = 1E-6
ISMEAR = 0 ; SIGMA = 0.05   ! insulator; for a metal use ISMEAR = 1 ; SIGMA = 0.2
IBRION = 2
ISIF   = 2            ! atoms only: surfaces, defects, molecules in a box
NSW    = 100
EDIFFG = -0.02
NELMIN = 4            ! 8 for complex surfaces
LCHARG = .FALSE. ; LWAVE = .FALSE.

ENCUT   = 520         ! the same cutoff as the relaxation
PREC    = Accurate
EDIFF   = 1E-6
ISMEAR  = -5          ! tetrahedron: Gamma-centred mesh, at least 4 k-points
NSW     = 0
IBRION  = -1
LORBIT  = 11          ! projected DOS and site moments
LMAXMIX = 4           ! 4 for d, 6 for f elements; keep it in runs that read CHGCAR
LCHARG  = .TRUE.      ! CHGCAR feeds the DOS and band runs
LWAVE   = .FALSE.

For the forces or stress of a metal in a static run, use ISMEAR = 1 ; SIGMA = 0.2 instead of −5.

ENCUT   = 520         ! the same as the run that wrote CHGCAR
PREC    = Accurate
ICHARG  = 11          ! read CHGCAR and keep the density fixed
ISMEAR  = -5
NEDOS   = 2001        ! a fine energy grid
LORBIT  = 11
NSW     = 0
LMAXMIX = 4           ! must match the self-consistent run
LCHARG  = .FALSE. ; LWAVE = .FALSE.

Copy CHGCAR from the static run and use a denser Γ-centred k-mesh than it had.

ENCUT   = 520
PREC    = Accurate
ICHARG  = 11
ISMEAR  = 0 ; SIGMA = 0.05  ! take E-fermi from the self-consistent run
LORBIT  = 11          ! orbital character of each band (PROCAR)
NSW     = 0
LMAXMIX = 4
LCHARG  = .FALSE. ; LWAVE = .FALSE.

KPOINTS holds the high-symmetry path in line mode; the KPOINTS sheet covers the format.

ISPIN  = 2
MAGMOM = 2*3.0              ! ferromagnet: one value per atom, in POSCAR order
# MAGMOM = 2*4.0 2*-4.0 4*0.0   ! antiferromagnet, e.g. two Mn up, two Mn down, four O
LORBIT = 11                 ! moment of each site in OUTCAR
LASPH  = .TRUE.
LMAXMIX = 4

Add these lines to any recipe above. Start the moments 1.2–1.5 × above the expected values; an antiferromagnet needs a cell that holds both sublattices, often a supercell. The magnetism sheet goes further.

METAGGA = R2SCAN      ! VASP 6.2.0 or later; avoid 6.6.0 for spin-polarized forces
LASPH   = .TRUE.
ALGO    = All
ISEARCH = 1           ! VASP 6.5.1 or later; delete it on older versions
EDIFF   = 1E-6

Add to a recipe above, with a converged ENCUT (Materials Project uses 680 eV for r²SCAN). Check that every POTCAR has kinetic-energy data: grep kinetic POTCAR. If the SCF struggles, start from a PBE WAVECAR; with ALGO = Normal, LMIXTAU = .TRUE. can help. Before VASP 6.6.0, band structures and DOS with a meta-GGA must follow the hybrid procedure below instead of ICHARG = 11; KPOINTS_OPT works on every version from 6.3.0.

LHFCALC  = .TRUE.
HFSCREEN = 0.2        ! HSE06; the exact-exchange fraction AEXX is 0.25 by default
ALGO     = All        ! direct optimization: the recommended choice for hybrids
ISEARCH  = 1          ! VASP 6.5.1 or later; delete it on older versions
ENCUT    = 520
PREC     = Accurate
EDIFF    = 1E-6
ISMEAR   = 0 ; SIGMA = 0.05
LASPH    = .TRUE.
NSW      = 0 ; IBRION = -1
LWAVE    = .TRUE.     ! hybrids are expensive: keep WAVECAR for restarts

Start from a converged PBE WAVECAR. Never use ICHARG = 11 with hybrids: for a band structure, put the path in a KPOINTS_OPT file (VASP 6.3.0 and later) or as zero-weight k-points, and for gapped systems set HFRCUT = -1. To relax the cell with a hybrid, set ISIF explicitly: its default is 0, which moves the atoms but computes no stress.

Check what VASP read

VASP prints your INCAR and, further down, the value it used for every parameter, defaults included. Read them before trusting a result.

# your INCAR as VASP read it (printed near the top of OUTCAR by VASP 6.2 and later)
awk '/^ INCAR:/{f=1;next} f&&/^ +[A-Za-z0-9_]+ = /{print;next} f{exit}' OUTCAR

# the values used, defaults included (VASP 5 and 6)
sed -n '/Startparameter for this run/,$p' OUTCAR | grep -E '^ +(PREC|ENCUT|EDIFF|EDIFFG|IBRION|ISIF|ISMEAR|ISPIN|LASPH) +='

# the same from vasprun.xml: matches inside  are your INCAR, those inside
#  the values used (there the cutoff is called ENMAX)
grep -E 'name="(ENCUT|ENMAX|ISMEAR|SIGMA|EDIFFG)"' vasprun.xml
